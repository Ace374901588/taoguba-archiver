# 单条淘股吧说说归档设计

## 目标

用户明确粘贴一条淘股吧“说说”链接后，软件在应用专用 Chrome Profile 的已登录状态下读取该页面，生成可离线浏览的 HTML 导出包。该功能不发现、遍历或批量抓取其他说说、用户页面、评论或转发链。

## 输入边界

- 只接受 HTTPS `shuo.tgb.cn/shuo/toViewShuo?shuoID=<数字>` 链接。
- CLI 使用 `--shuo URL`；它不能与文章 URL、`--urls-file` 或 `--reply-feed` 共用。
- 网页工作台提供独立的“单条说说归档”URL 输入框和按钮。
- 该模式固定输出 HTML，不提供 Markdown；使用有界面 Chrome，避免站点拒绝无界面请求。

## 归档内容

每次运行创建一个新目录，其中包含：

- `shuo.html`：脱离网络后仍可阅读的正文页。
- `images/`：只保存说说正文内的内容图片，不保存头像、表情或页面装饰资源。
- `metadata.json`：原始 URL、作者、发布时间、正文摘要、图片清单、HTTP 状态、完整性与哈希。
- `response.html` 和 `rendered.html`：安全的响应/渲染诊断副本。

HTML 显示作者、发布时间、原始链接和正文。所有图片都改写为相对本地路径；脚本、事件处理器和远程嵌入内容会移除。

## 数据流与失败处理

1. 校验 URL。
2. 在后台线程创建并使用应用专用 Playwright Profile，读取该单一 URL。
3. 保存安全响应和渲染 DOM，解析正文及内容图片。
4. 下载图片并生成可移植 HTML 与元数据。
5. 对非 2xx/3xx 响应、登录提示或未识别到正文的页面标记为 `incomplete`，但仍保留诊断文件；绝不导出 Cookie、令牌或 `Set-Cookie`。

## 组件边界

- `shuo.py`：URL 校验、结构化解析、内容图片筛选和 HTML 渲染。
- `browser.py`：单条页面获取、文件写入、图片下载、完整性判断。
- `service.py`：CLI/网页共用的 `archive_shuo` 入口。
- `cli.py` 与 `web.py`：显式输入入口及互斥参数检查。

文章和最新跟帖逻辑不改变；说说解析器不依赖或扫描它们的链接。

## 测试与验收

- URL 校验拒绝非 `shuo.tgb.cn`、错误路径和缺失/非数字 `shuoID`。
- HTML 夹具验证作者、时间、正文、图片本地化和危险标签清理。
- 浏览器导出测试验证诊断文件、无秘密元数据及失败状态。
- CLI 与网页测试验证显式入口和参数互斥。
- 运行完整单元测试、CLI 帮助/冒烟与静态检查；用用户提供的一条说说 URL 做已登录真实回归。
